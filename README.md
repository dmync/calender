# Simple Web Calendar

## About the Project

This project is a simple interactive web calendar developed using HTML, CSS, and JavaScript. It displays monthly calendar dates and allows users to navigate between different months and years.

The calendar also highlights weekends, the current date, and Sri Lankan Poya days.

## Features

- Display monthly calendar dates
- Navigate to previous and next months
- Navigate to previous and next years
- Highlight weekends
- Highlight the current date
- Identify and highlight Sri Lankan Poya days
- Simple and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the navigation buttons to explore different months and years.

## Purpose

This project was developed to improve practical skills in HTML, CSS, and JavaScript, particularly DOM manipulation, date handling, and event handling.
